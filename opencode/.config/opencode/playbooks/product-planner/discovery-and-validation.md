# Discovery and Validation Playbook

Use this playbook when you need to:

- clarify user problems before locking scope
- set up discovery cadence
- build assumptions and experiments

## Output contract

1. Outcome and target metric
2. Top user segments and contexts
3. Opportunity map (pain points, needs, jobs)
4. Assumption register (D/V/F/U/E)
5. Experiment backlog (ranked)
6. Decision and next actions

## Assumption categories

- Desirable: users want this and will adopt it.
- Viable: supports business goals/economics.
- Feasible: can be built within constraints.
- Usable: users can understand and complete flows.
- Ethical: avoids harmful/manipulative outcomes.

## Experiment ladder (cheap to expensive)

1. Problem interviews
2. Workflow walkthroughs / paper tests
3. Low-fidelity prototypes
4. Concierge / manual pilot
5. Limited beta with instrumentation

## Weekly discovery cadence

- 3-5 customer conversations per week (or best possible cadence).
- Weekly assumption review.
- Weekly experiment planning for next sprint/cycle.

## Minimum evidence before build commitment

- Core problem confirmed by target users.
- At least one high-risk assumption validated or de-risked.
- Clear success metric and baseline.
