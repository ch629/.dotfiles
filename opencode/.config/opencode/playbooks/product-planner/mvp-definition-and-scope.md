# MVP Definition and Scope Playbook

Use this playbook when defining what ships in v1.

## Output contract

1. MVP goal (single clear outcome)
2. Must-have capabilities
3. Explicit non-goals
4. MVP acceptance criteria
5. Launch readiness checks
6. Kill/pivot criteria

## Scope guardrails

- If an item is not required for core user value, move it out of MVP.
- Prefer one reliable core workflow over many partial workflows.
- Include observability in MVP (events, funnel, errors).
